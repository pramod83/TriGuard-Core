TriGuard Core — Data, Icon & Audio Control

An all-in-one, lightweight Magisk, KernelSU, and APatch WebUI module engineered by Pramod Kumar for complete foreground network privacy, universal launcher icon hiding, and strict hardware audio level locking.

Download Latest ZIP (v1.0-Stable) View Source on GitHub

Three Unified Control Engines in One WebUI

1. NetVault — Foreground-Only Internet Firewall

NetVault dynamically manages Linux iptables and ip6tables rules so that mobile data and Wi-Fi access are granted strictly to the app currently visible on your screen. Background apps remain blocked from silent data drain unless explicitly whitelisted in the WebUI, and all non-whitelisted traffic pauses automatically when the screen turns off.

2. IconCloak — Universal Launcher Icon Hider

IconCloak hides all launcher entry activities of selected applications across Vivo (Funtouch OS), OnePlus (OxygenOS), Oppo (ColorOS), Realme, Xiaomi, Samsung, and Pixel launchers. An active background auto-relock watcher ensures Home button presses never unhide your locked apps, while background services, alarms, and push notifications continue operating normally.

3. SoundHold — Strict Per-Stream Volume & Ringer Locker

SoundHold locks individual Android audio streams—Call, Ring, Media, Notification, and Alarm—at your chosen volume levels. When Ring lock is active above zero, SoundHold also prevents accidental silent or vibrate overrides, with instant single-stream lock buttons alongside one-tap Lock All and Unlock All controls.

Built-In Safety, Diagnostics & OTA Updates

  • Passive Anti-Bootloop Self-Guard: Uses non-blocking background execution and tracks only TriGuard Core's own boot state, automatically disabling the module if two consecutive boots fail before completion without interfering with third-party bootloop protectors.
  • Live Diagnostic Action Button: Tapping the Action button inside Magisk Manager prints real-time status for the background daemon, NetVault firewall chain, locked hidden icon count, and locked audio streams.
  • In-App OTA Updates: Configured with pk-triguard-ota.json so Magisk Manager automatically notifies users when a new stable version is released.

How to Install & Configure

  1. Download TriGuard-Core-v1.0-Stable.zip from the official GitHub Releases page.
  2. Open Magisk (v20.4+), KernelSU, or APatch, go to the Modules tab, and flash the ZIP file from storage.
  3. Reboot your Android device to initialize the background engine.
  4. Launch KSUWebUIStandalone or MMRL to manage NetVault, IconCloak, and SoundHold from one unified dashboard.
